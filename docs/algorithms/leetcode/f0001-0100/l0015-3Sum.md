## Stage B｜解題分析：完成第一次實作後再看

### 1. 看到這題，怎麼想到要用排序與固定一個值後的雙指標？

枚舉三個位置要三層迴圈。固定 −1 後，其餘兩數只需相加等於 1，就變成排序版 Two Sum。先排序使兩端可以安全排除，也讓相同值聚在一起方便去重。Set 可以去掉已輸出的重複組，但若先枚舉全部三元組，仍做 O(n³) 次工作；真正省時的是讓內部配對從平方變線性。

**下次可以怎麼想：** 固定一部分後若剩下的是已知較簡單的配對問題，就沿用其排除規則，並另想清楚全部答案的去重。

### 2. 暴力解／最直接的正確解

列舉 i&lt;j&lt;k，命中就把三個值排序作代表，保存唯一三元組。

#### TypeScript

```ts
function threeSumBrute(nums: number[]): number[][] {
  const found = new Map<string, number[]>();
  for (let i = 0; i < nums.length; i++) for (let j = i + 1; j < nums.length; j++) {
    for (let k = j + 1; k < nums.length; k++) {
      if (nums[i] + nums[j] + nums[k] === 0) {
        const row = [nums[i], nums[j], nums[k]].sort((a, b) => a - b);
        found.set(JSON.stringify(row), row);
      }
    }
  }
  return [...found.values()];
}
```

#### Python

```python
def three_sum_brute(nums: list[int]) -> list[list[int]]:
    found: set[tuple[int, ...]] = set()
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            for k in range(j + 1, len(nums)):
                if nums[i] + nums[j] + nums[k] == 0:
                    found.add(tuple(sorted((nums[i], nums[j], nums[k]))))
    return [list(row) for row in found]
```

### 3. 暴力解的瓶頸

位置組合有 n(n−1)(n−2)/6 種，n=3000 時約 45 億種。最後用 Set 去重並未減少這些列舉。

### 4. 從瓶頸推導資料結構／演算法

排序副本後固定 i，內部 left=i+1、right=n−1。和太小移左、太大移右；命中後兩端都移，再跳同值。固定 i 也跳過相同值，所以不需要結果 Set。

### 5. 為什麼是這個資料結構／方法

排序成本需計入。每個固定 i 的兩個指標各單向走 O(n) 步；比較、加法 O(1)。輸出可能很多，不能稱整個解法只有 O(1) 空間。

### 6. 最佳解法步驟

1. 複製並做數值排序。
2. 遍歷固定位置，跳過重複值；固定值大於 0 可停止。
3. 用雙指標找配對，依總和移動。
4. 命中加入三元組，移動兩端並跳過重複值。

### 7. 核心不變量：每輪都要保持什麼

固定 i 的內層始終滿足 i&lt;left&lt;right；已排除配對不可能形成未回傳的有效三元組。重複 i 被跳過，命中後相同兩端值不再產生同一數值組。

### 8. 手動演算

| 已排序 [-4,-1,-1,0,1,2] | left,right 值 | 和／動作 |
| --- | --- | --- |
| 固定 -4 | -1,2 | -3，向右找，最終無解 |
| 固定第一個 -1 | -1,2 | 0，加入 [-1,-1,2] |
| 同一固定值 | 0,1 | 0，加入 [-1,0,1] |
| 固定第二個 -1 | — | 跳過重複固定值 |

### 9. 完整實作

以下函式可直接拿來做本機練習。提交 LeetCode 時，依編輯器模板保留要求的函式名稱；Python 可放進 `class Solution` 並加上 `self`，其餘演算法相同。

#### TypeScript

```ts
function threeSum(nums: number[]): number[][] {
  const sorted = [...nums].sort((a, b) => a - b);
  const result: number[][] = [];
  for (let i = 0; i < sorted.length - 2; i++) {
    if (i > 0 && sorted[i] === sorted[i - 1]) continue;
    if (sorted[i] > 0) break;
    let left = i + 1, right = sorted.length - 1;
    while (left < right) {
      const sum = sorted[i] + sorted[left] + sorted[right];
      if (sum < 0) left++;
      else if (sum > 0) right--;
      else {
        result.push([sorted[i], sorted[left], sorted[right]]);
        left++; right--;
        while (left < right && sorted[left] === sorted[left - 1]) left++;
        while (left < right && sorted[right] === sorted[right + 1]) right--;
      }
    }
  }
  return result;
}
```

#### Python

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    values = sorted(nums)
    result: list[list[int]] = []
    for i in range(len(values) - 2):
        if i > 0 and values[i] == values[i - 1]:
            continue
        if values[i] > 0:
            break
        left, right = i + 1, len(values) - 1
        while left < right:
            total = values[i] + values[left] + values[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([values[i], values[left], values[right]])
                left += 1
                right -= 1
                while left < right and values[left] == values[left - 1]:
                    left += 1
                while left < right and values[right] == values[right + 1]:
                    right -= 1
    return result
```

### 10. 複雜度分析

排序通常 O(n log n)，n 個固定值各 O(n) 掃描，總 O(n²)。本頁複製輸入 O(n)，排序暫存依 runtime，Python sort 最差 O(n)；輸出 r 組需 O(r)，r 可達 O(n²)。因此計輸出 O(n+r)，不是 O(1)。ECMAScript 未對 sort 的時間／空間作統一保證，此處採常見排序實作成本。

### 11. 邊界條件與常見錯誤

JavaScript sort 未給數值 comparator；只去重固定值卻不去重兩端；找到一組立即 return 而漏掉其他解；原地排序改壞呼叫端資料；把相同數值誤當不能使用不同位置。

### 12. 為什麼不用其他方法

固定一值加 Hash 查另外兩值，也可平均 O(n²)，但去重與暫存更複雜。若需要原索引，排序應保存位置，而且「相同數值組」和「不同索引組」是不同輸出契約。
