# Day 262｜Part 4 慈善音樂會廣播

影片：[Carol Bai｜Day 262 TOEIC 聽力 Part 4](https://www.youtube.com/watch?v=hEqsvmvO8Ss&list=PLP1Fn0SBWu6eUOKuF9RdbicWF5jSBV_Ew&index=13)

這集練習**夏季慈善音樂會的電台公告**。Part 4 是單人獨白，先辨認公告目的，再記下地點、票價、入園限制，以及限制背後的原因。

## 資訊擷取框架

| 要找的資訊 | 聆聽重點 |
| --- | --- |
| 活動目的 | 音樂會為什麼舉辦？留意 *raise funds for ...* 後面的對象。 |
| 地點與費用 | 留意舉辦地點、入口與票價；數字要與它修飾的項目一起記。 |
| 入園限制 | 哪個區域 *closed to the general public*？限制適用於誰？ |
| 原因 | *to ensure security* 說明為什麼需要限制入園。 |

影片說明特別提醒：聽到 **to ensure security** 時，要把它連回公園關閉的原因。這是「措施 → 原因」的線索；作答時不要只因選項提到公園就選它，還要核對開放對象和限制條件。

## 核心詞彙

| 英文 | 中文 | 記法 |
| --- | --- | --- |
| radio announcement | 電台公告 | 先判斷說話者在通知聽眾什麼。 |
| charity concert | 慈善音樂會 | *charity* 表示慈善。 |
| raise funds for ... | 為……籌款 | *for* 後面通常是受益對象或用途。 |
| entrance | 入口 | 留意與地點、入場方式有關的資訊。 |
| secure / security | 確保安全／安全 | *to ensure security*＝為了確保安全。 |
| closed to the general public | 不對一般大眾開放 | *closed to* 後面接被限制進入的人。 |

## 聽力練習

1. [00:13 題目 Q94–96](https://www.youtube.com/watch?v=hEqsvmvO8Ss&t=13s)：先盲聽，畫出「活動、地點、票價、限制、原因」五格。
2. [00:54 中英字稿講解](https://www.youtube.com/watch?v=hEqsvmvO8Ss&t=54s)：核對 *raise funds for*、*closed to the general public* 等關鍵片語。
3. [02:24 答案解析](https://www.youtube.com/watch?v=hEqsvmvO8Ss&t=144s)：對照自己的五格筆記，找出漏聽的是數字、地點還是因果關係。
