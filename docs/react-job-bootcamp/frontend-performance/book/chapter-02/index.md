# Chapter 02｜網頁資源優化

把位元組、請求、圖片品質與載入優先序放在同一個決策裡。

## 這一章在解決什麼

資源優化要同時考慮檔案本身與交付時機。程式碼可以縮小、刪除或延後；圖片要選格式、像素尺寸及畫質；文字回應可用 Brotli／Gzip；適性服務則依使用者情境調整品質。

## 怎麼決定先讀哪一節

先看 Network 的最大資源與 LCP 元素。若資源下載太慢，調整格式／大小／壓縮；若開始太晚，調整資源發現與優先序；若下載已完成但畫面仍晚出現，轉查渲染。

## 本章學習方式

先選一個自己的頁面，照每節的「從頭做一次」保存基準值與操作紀錄。讀完後，把每節的結果連回同一個使用者任務，判斷最大瓶頸是否已經改變。
