# Chapter 07｜記憶體與渲染架構

處理長時間使用的穩定性與頁面交付方式。

## 這一章在解決什麼

長時間使用的產品需要同時注意記憶體穩定與首屏交付方式。記憶體洩漏會使越用越卡，渲染架構則影響第一次進站、後續導覽、資料新鮮度和伺服器成本。

## 怎麼決定先讀哪一節

反覆開關元件後 heap 持續成長，先沿 retained path 查引用；首屏慢則比較 TTFB、LCP、JS 與 hydration，再按頁面選 CSR／SSR／SSG。

## 本章學習方式

先選一個自己的頁面，照每節的「從頭做一次」保存基準值與操作紀錄。讀完後，把每節的結果連回同一個使用者任務，判斷最大瓶頸是否已經改變。
