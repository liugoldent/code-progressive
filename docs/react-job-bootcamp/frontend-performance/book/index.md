## 使用順序

1. 先讀 Chapter 01，定義頁面、使用者操作與 baseline。
2. 根據實際瓶頸進入對應章節；每一節都有「實作與驗證」，照著在自己的頁面重現。
3. 需要更長的逐日說明時，使用每節末尾的 Day 連結。

## 閱讀與核對範圍

**8 章、31 小節的正文已按電子書閱讀器順序逐頁核對**，各小節的「書籍逐頁核對」標出對應紙本頁碼，整理該頁段的論點與範例。每節另有「問題與解答」，把觀念改寫成可自我測驗的具體問題，回答原因、適用時機與驗證方法。前半部原有的「核心觀念／從頭做一次」是獨立技術補充；兩種內容分開標示，方便分辨哪些是書中實際談到的、哪些是延伸實務。筆記以自己的話歸納，並未重製書中文字或圖片。核對範圍是正文各小節，未將封面、目錄、參考資源附錄當作教學章節。書中部分工具畫面、框架 API 和效能指標已有版本差異；實作時仍請核對 [web.dev Core Web Vitals](https://web.dev/articles/vitals) 等現行官方文件。
