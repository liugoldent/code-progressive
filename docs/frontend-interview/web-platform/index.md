# Web Platform 中高階面試實戰題

這組題目假設你已經有多年開發經驗，不練「`div` 和 `span` 的差別」這類記憶題，而是練面試官更容易繼續追問的三件事：

1. 能不能預測實際行為。
2. 能不能解釋瀏覽器或框架為什麼這樣運作。
3. 能不能在限制條件下選方案，並說出 trade-off。

## 建議練法

每題先用 60～90 秒口述，不急著展開答案。回答至少包含：

- **結論**：畫面或程式會怎麼表現。
- **機制**：是哪個規則造成的。
- **處理**：怎麼修，為什麼選這個方案。
- **驗證**：會用 DevTools、測試或效能指標驗證什麼。

答得出名詞只是起點；能處理追問與反例，才接近資深工程師的面試深度。
